# Verification record — 2026-10-01

The project is being changed from an independent behavioral runtime into a source-method port of the supplied Java original. Selected original classes are now connected to the C11 client/server. The existing creative runtime, GUI/controller/server handlers and most dependencies are not complete source ports. This record establishes only the named tests below, not full source translation or Minecraft feature parity. See `porting.md` for exact class/method boundaries.

Native Runtime bindings connect original recipe/stat identities, source inventory handlers, SP/controller actions, metadata and original map tracking to real TCP and all-player version-3 durability. The old value adapters remain for historical tests; they no longer own the live inventory/cursor/item state.

## Unverified or unsupported

Vanilla Minecraft GUI gameplay and live keyboard/mouse/IME input were not manually exercised. The native framebuffer and protocol paths were exercised; GUI input wiring was inspected and targeted helpers were tested. An online-mode server requires authentication/encryption that this initial version explicitly does not implement.

The renderer uses independently generated cube materials and symbolic item geometry. It does not reproduce all block models, transparency, textures or lighting. Simple collision shapes cover tested slabs/stairs/carpet/snow and local shapes; neighbour-dependent connections and full physics remain incomplete. Item physics lacks water flow, continuous burning/extinguishing and complete audiovisual effects. Chat text and `extra` fields are supported; translation, rich styles and localization are simplified. The dedicated server has a bounded 7×7-chunk creative world, bounded item snapshots and at most 96 maps. Map surveying covers supported loaded overworld terrain. Initial/full, dirty-rectangle and icons-only scheduling now use the ported MapInfo. Full dimensions, ItemFrame, complete source dependencies and original collection tie behavior remain open. Other external container screens, Survival, mobs, redstone, Anvil world saves and Java mods are not implemented. Registry inclusion does not imply every item's gameplay behaviour or complete creative variant coverage.

GitHub-hosted CI is configured separately. Its status must be checked from the actual pushed commit; local results alone do not establish remote CI success.
